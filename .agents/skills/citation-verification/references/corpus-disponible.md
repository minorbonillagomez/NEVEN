## Temas cubiertos por libro

### Wooldridge — Introductory Econometrics
- Cap. 1-2: Introducción, modelo de regresión simple
- Cap. 3-4: Regresión múltiple, inferencia
- Cap. 5-6: Propiedades asintóticas, especificación
- Cap. 7-9: Variables dummy, heterocedasticidad, más sobre especificación
- Cap. 10-12: Series de tiempo básico
- Cap. 13-14: Datos de panel
- Cap. 15: Variables instrumentales
- Cap. 17: Modelos de respuesta limitada (Tobit, Probit)

**Mejor para**: Explicaciones pedagógicas, supuestos, interpretación.

### Greene — Econometric Analysis
- Cap. 1-5: Algebra matricial, modelo clásico
- Cap. 6-9: Inferencia, especificación, datos de panel
- Cap. 14-17: MLE, modelos discretos, variables truncadas
- Cap. 19-21: GMM, modelos de series de tiempo

**Mejor para**: Teoría formal, demostraciones, métodos avanzados.

### Hamilton — Time Series Analysis
- Cap. 1-4: Modelos AR, MA, ARMA
- Cap. 5-7: Máxima verosimilitud, pronóstico
- Cap. 15-18: Cointegración, VAR, ECM
- Cap. 19-22: Modelos con varianza condicional (GARCH)

**Mejor para**: Series de tiempo, estacionariedad, VAR, cointegración.

## Cómo citar

### Formato estándar
```
[Afirmación]. (Autor, Libro, Cap. X)
```

### Ejemplos válidos
```
El estimador MCO es BLUE bajo los supuestos de Gauss-Markov (Wooldridge, Cap. 3).

El test ADF tiene baja potencia contra alternativas cercanas a la raíz unitaria (Hamilton, Cap. 17).

El modelo de efectos fijos elimina la heterogeneidad no observada invariante en el tiempo (Wooldridge, Cap. 13).
```

### Ejemplos inválidos
```
❌ "La literatura econométrica establece que..."
   (No especifica qué literatura)

❌ "Wooldridge señala que siempre debemos usar errores robustos"
   (Wooldridge no dice "siempre", está mal atribuido)

❌ "Según Greene (1993)..."
   (Año incorrecto, Greene 8th ed. es de 2018)
```

## Cuando el tema NO está en el RAG

### Respuesta honesta
```
"Este tema específico (por ejemplo, métodos de machine learning 
para causalidad) no está cubierto en mis fuentes de econometría 
clásica. Para esto, recomiendo consultar literatura especializada 
en machine learning o causal inference."
```

### Redirigir a lo disponible
```
"Aunque no tengo información sobre [topic X], puedo explicar 
[topic Y relacionado] que Wooldridge cubre en el Cap. Z."
```

## Regla de oro

> **Si no puedo citar la fuente exacta, no es una afirmación que deba hacer como si fuera del RAG.**

Las opiniones generales, conocimiento común, o experiencia práctica pueden expresarse, pero claramente marcados como tales — no como si vinieran de los libros indexados.
