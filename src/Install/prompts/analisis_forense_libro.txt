## METODOLOGIA DE ANALISIS

### 1. INVENTARIO ESTRUCTURAL
Para cada hoja del libro, documentar:
- Nombre de la hoja y proposito inferido
- Rango de datos utilizado (primera/ultima fila y columna con datos)
- Estructura de encabezados (fila de titulos, jerarquias)
- Tipos de datos por columna (numerico, texto, fecha, formula, etc.)
- Celdas combinadas y su proposito
- Areas de impresion definidas
- Filtros y tablas estructuradas

### 2. ANALISIS DE FORMULAS Y DEPENDENCIAS
- Identificar todas las formulas presentes
- Mapear dependencias entre celdas (precedentes y dependientes)
- Detectar referencias entre hojas (flujo de datos inter-hojas)
- Identificar referencias externas a otros libros
- Clasificar formulas por tipo: calculos, busquedas (VLOOKUP, INDEX-MATCH), agregaciones, condicionales
- Detectar formulas circulares o errores (#REF!, #VALUE!, #N/A)

### 3. TAXONOMIA ONTOLOGICA
Clasificar los elementos encontrados segun estas categorias:

ENTIDADES:
- Maestros de datos (clientes, productos, empleados, cuentas)
- Transacciones (ventas, compras, movimientos, asientos)
- Catalogos (listas de valores, parametros)
- Resultados calculados (totales, indicadores, KPIs)

PROCESOS:
- Captura de datos (entrada manual, importacion)
- Transformacion (calculos, conversiones, validaciones)
- Agregacion (subtotales, resumen, consolidacion)
- Presentacion (reportes, dashboards, graficos)

RELACIONES:
- Uno a uno, uno a muchos, muchos a muchos
- Jerarquias (padre-hijo, arbol)
- Temporales (periodos, versiones)

### 4. FLUJO DE PROCESO
Documentar el flujo logico del libro:
- Punto de entrada de datos (donde inicia el proceso)
- Transformaciones intermedias
- Salidas y resultados finales
- Dependencias criticas (que debe existir para que funcione)

### 5. EVALUACION DE CALIDAD
- Consistencia de formatos y nomenclatura
- Validaciones de datos implementadas
- Proteccion de celdas/hojas
- Documentacion existente (comentarios, notas)
- Riesgos identificados (hardcoding, referencias fragiles)
