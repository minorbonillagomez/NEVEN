## 🔴 PRIORIDAD ALTA

| # | Función | Origen | Descripción |
|---|---------|--------|-------------|
| 1 | **Calendar Widget Integrado** | MSFT | Vista de agenda que muestra próximos eventos inline en home screen. Estilo minimalista científico. |
| 2 | **Swipe Actions en Apps** | Niagara | Deslizar izq/der sobre app favorita para acciones rápidas (info, desinstalar, ocultar) |
| 3 | **App Shortcuts / Deep Links** | Niagara | Long-press muestra accesos directos nativos de Android (ej: WhatsApp → Nuevo chat, Camera → Selfie) |
| 4 | **Gestos Globales** | Niagara | Doble-tap = apagar pantalla, Swipe down = búsqueda/notificaciones |
| 5 | **Búsqueda Universal** | MSFT | Buscar apps, contactos, archivos, web, todo desde un solo campo |

## 📅 Plan de Sesiones Sugerido

### Sesión 1: Calendar Widget
- Integración con Calendar Provider de Android
- Mostrar próximos 3-5 eventos debajo del reloj
- Estilo científico/académico consistente con NEVEN
- Tap en evento → abrir app de calendario

### Sesión 2: Swipe Actions + Gestos Globales
- Swipe derecha/izquierda en favoritos
- Doble-tap para apagar pantalla
- Configuración de gestos personalizable

### Sesión 3: App Shortcuts + Búsqueda Universal
- API de ShortcutManager de Android
- Campo de búsqueda integrado
- Buscar apps, contactos, configuraciones

### Sesión 4: Ocultar Apps + Folders Inteligentes
- Lista de apps ocultas
- Categorización automática de apps
- Carpetas colapsables en drawer

### Sesión 5: Notas Rápidas + Glance Feed
- Widget de notas flotante
- Panel informativo deslizable
- Integración con servicios de Microsoft (opcional)

### Sesión 6: Weather + Media Controls + Polish
- Widget de clima minimalista
- Controles de reproducción
- Refinamiento general de UX
