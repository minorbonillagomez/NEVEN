### Ecuaciones en bloque

La integral de Gauss:

$$\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}$$

Sumatoria:

$$\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$$

Teorema de Euler:

$$e^{i\pi} + 1 = 0$$

## Codigo

Codigo inline: `print("Hola mundo")`

Bloque de codigo:

```python
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

for i in range(10):
    print(fibonacci(i))
```
