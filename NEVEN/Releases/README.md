# NEVEN Releases

Este directorio contiene los paquetes de instalación listos para distribución.

## v3.2 (Agosto 2026)

- **NEVEN-v3.2-Setup.zip** (21.7 MB)
  - Instalador completo para usuario final
  - Incluye: XLL, Ribbon, ControlR/Julia/Python, TaskPane, documentación, ejemplos
  - Requisitos: Windows 10+ 64-bit, Excel 2016+, R 4.4.1+

### Instalación

1. Descomprimir `NEVEN-v3.2-Setup.zip`
2. Ejecutar `Install-NEVEN.exe` como administrador
3. Seguir las instrucciones del instalador
4. Reiniciar Excel

### Novedades v3.2

- Integración Python completa (Stable ABI)
- NEVEN Studio (TaskPane interactivo)
- Botones Iniciar/Detener Servidor en Ribbon
- Sistema de aliases para funciones
- Documentación actualizada (15 capítulos)
