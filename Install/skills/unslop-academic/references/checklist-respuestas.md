# Checklist de Calidad de Respuestas

## Antes de enviar cualquier respuesta

### 1. Eliminación de slop
- [ ] ¿Eliminé "es importante destacar"?
- [ ] ¿Eliminé "juega un papel crucial/pivotal"?
- [ ] ¿Eliminé "en el panorama actual"?
- [ ] ¿Eliminé "una amplia gama de"?
- [ ] ¿Reemplacé "mejora significativamente" con números?

### 2. Especificidad
- [ ] ¿Cada afirmación tiene evidencia concreta?
- [ ] ¿Los números son específicos (no "muchos", "varios")?
- [ ] ¿Nombré exactamente qué (variables, tests, métricas)?

### 3. Estructura
- [ ] ¿Primera oración responde directamente la pregunta?
- [ ] ¿Explicación sigue, no precede, al punto principal?
- [ ] ¿Sin rodeos introductorios?

### 4. Fuentes
- [ ] ¿Cada afirmación técnica está respaldada?
- [ ] ¿Citas en formato: Autor, Libro, Capítulo?
- [ ] ¿No inventé ninguna referencia?

---

## Reemplazos rápidos

| Escribí | Debo reemplazar con |
|---------|---------------------|
| importante | [eliminar o especificar por qué] |
| significativo | el valor: "15% mayor" |
| notable | "de 3.2 a 5.1" |
| diversos/varios | el número: "7 de 10" |
| ampliamente | "en 95% de casos" |
| crucial | "necesario para" o "causa" |
| robusto | qué lo hace robusto |
| prometedor | los resultados específicos |

---

## Patrones de respuesta

### Pregunta conceptual
```
[Respuesta directa en 1-2 oraciones]

[Fórmula si aplica]

[Ejemplo numérico]

[Limitaciones/cuándo no aplica]

Fuente: Autor, Libro, Cap. X
```

### Pregunta sobre código
```
[Código que resuelve el problema]

[Explicación de qué hace cada parte]

[Output esperado]
```

### Interpretación de resultados
```
[Qué significan los números principales]

[Si son buenos/malos según contexto]

[Qué hacer a continuación]
```
